# Software licensing status

This repository is publicly available for research transparency and reproducibility, but **no open-source software licence is granted at present**.

The original DragNet research software was developed collaboratively in work affiliated with the University of Leeds. The DragNet paper credits both Arezoo Zakeri and Alireza Hokmabadi with software contributions. University of Leeds intellectual-property policy states that IP created by staff in the course of employment is normally owned by the University and includes additional rules for jointly created student/staff IP.

Accordingly, this repository does not assert that any one contributor can unilaterally grant an MIT, BSD, Apache, GPL, or other open-source licence over the original DragNet implementation or derivative implementation material.

The associated article is available under Creative Commons Attribution 4.0, but that publication licence applies to the article and does not automatically license this separate software implementation.

The source is published here because the DragNet article states that the code would be made publicly available. Public source availability should not be interpreted as permission to reuse, modify, redistribute, sublicense, or commercialise the software beyond rights provided by applicable law and the hosting platform's terms.

If the relevant rights holder(s) later confirm an open-source licence in writing, this file can be replaced by that licence.
